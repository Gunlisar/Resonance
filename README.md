# Resonance

Resonance — музыкальный плеер для Mac с Apple silicon (macOS 14 и новее).

[Скачать последнюю версию](https://github.com/Ronsena-dev/Resonance/releases/latest)

После первой установки Resonance проверяет обновления при запуске. Управление обновлениями находится в разделе «Настройки → Общие».
